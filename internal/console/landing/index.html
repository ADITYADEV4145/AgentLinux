CLEAR BOUNDARIES

A separate workspace, not a security guarantee.

Linux, not your Mac

Agent controls target the Linux guest rather than your Mac desktop.

Explicit file transfers

Copy files in and out explicitly. Host home-directory mounting and clipboard sharing are off by default.

Networking has limits

Default networking can reach host and LAN services. This is not complete isolation.

Apache-2.0 core

Inspect the original open-source core, contribute improvements and review the license.

Normal Linux software

Install packages, apply updates and use guest-side drag through CLI or MCP.

You manage the lifecycle

Closing the viewer does not stop Linux. Explicitly stop, restart, reset or delete.
