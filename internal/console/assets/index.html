LOCAL · DEVELOPER RC

Your Mac. Your machine.

Persistent Debian 13 + Xfce desktop on Apple silicon. Agent controls target the guest. No home directory mounts or host clipboard sharing by default.

agent-linux

Lima 2.2.1 required. First boot downloads and provisions the guest. Bare command starts only from an interactive terminal.
