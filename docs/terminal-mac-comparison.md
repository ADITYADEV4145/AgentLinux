# terminal-mac comparison and local UX follow-up

Source inspection on 2026-11-05: [terminal-mac](https://github.com/govijr/terminal-mac), commit `cdad51fdb7faafc1761a2595823da96b83afde03`, MIT. Read-only inspection; no third-party code was copied, built or executed. Our original code remains Apache-2.0.

A repository cannot establish that a product is the market's fastest or best. Their [validation report](https://github.com/govijr/terminal-mac/blob/cdad51fdb7faafc1761a2595823da96b83afde03/docs/VALIDATION.md) explicitly leaves live VM/viewer acceptance pending. We compared implementation choices, not marketing or measured smoothness.

| Area | Their source | Agent Linux today | Decision |
| --- | --- | --- | --- |
| Capture | Persistent ScreenCaptureKit changed-frame stream; LZ4 BGRA; viewer-sized capture; configured 30 FPS ceiling | Real Linux X11/scrot PNG; pinned SSH request per operation; bounded capture hub and duplicate suppression | Keep correct guest-only controls. Persistent guest stream/pinned SSH reuse remains a measured optimization experiment, not implemented in this follow-up. |
| Rendering | Background latest-frame slot; optional Kitty shared memory; image double buffering; iTerm2/direct alternatives | Kitty chunked direct PNG; one cached frame; authenticated live web fallback | Keep portable correctness; shared memory and asynchronous presentation require explicit profiling/cleanup work. No FPS promise. |
| Cross-process responsiveness | Streaming observes desktop changes continuously | Previously static backoff could delay MCP-induced changes for up to five seconds | Implemented a private atomic advisory revision after local mutations. Separate viewer processes reset backoff when revision changes. |
| Human control | Drag press/release and multiple clicks, shortcut palette | Guest click/scroll/text/keys, Unicode and F2 ownership handoff; CLI/MCP drag supported | Keep human/agent lease. Human terminal drag and shortcut palette remain gaps. |
| Entry point | Bare interactive command and guided first run | `agent-linux start` was available | Bare `agent-linux` now calls the same real start/resume + interactive viewer path when stdin/output are TTYs. Piped invocation prints help. |
| Guest | macOS VM, Apple VZ, guest helper; scoped host exchanges | Debian 13 ARM64 full Xfce desktop through Lima/VZ; MCP/common local-cloud contract | Linux package ecosystem and guest-only automation remain our focus. No home mounts/host clipboard added for visual speed. |
| Distribution | Release installer, cached artifacts; signing/notarization caveats | Reproducible developer bundle and guarded user installer; no authorized public signed release | Do not invent a working public download/install URL. Prerequisites remain documented. |

Primary implementation references: [GuestCapture.swift](https://github.com/govijr/terminal-mac/blob/cdad51fdb7faafc1761a2595823da96b83afde03/Sources/TerminalMac/GuestCapture.swift), [DesktopRenderer.swift](https://github.com/govijr/terminal-mac/blob/cdad51fdb7faafc1761a2595823da96b83afde03/Sources/TerminalMac/DesktopRenderer.swift), [Viewer.swift](https://github.com/govijr/terminal-mac/blob/cdad51fdb7faafc1761a2595823da96b83afde03/Sources/TerminalMac/Viewer.swift), [FirstRun.swift](https://github.com/govijr/terminal-mac/blob/cdad51fdb7faafc1761a2595823da96b83afde03/Sources/TerminalMac/FirstRun.swift). Protocol reference remains the [official Kitty graphics specification](https://sw.kovidgoyal.net/kitty/graphics-protocol/); this follow-up does not change wire encoding or add unverified terminal compatibility.

The advisory revision contains only a fresh random ID, in a 0600 file inside the existing private machine namespace. It is neither readiness evidence nor a security boundary. Missing/malformed/unwritable signals retain periodic capture. An ambiguous mutation also wakes capture, but is never automatically retried. The file is included in guarded reset/delete ownership boundaries. No new listener, guest mount or desktop content log is introduced.

Next performance experiment: persistent viewer-scoped pinned SSH, bounded per-call cancellation and guest restart detection, then a measured changed-frame stream. Require real-Mac screenshot-to-input verification and whole-process CPU/RSS measurements before changing the default interval or advertising improvements. This implementation corrects backoff invalidation; it does not claim to have eliminated repeated SSH setup.
