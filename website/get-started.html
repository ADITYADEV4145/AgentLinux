FREE LOCAL DEVELOPER EDITION

Your agent’s Linux computer starts on your Mac.

A real Linux desktop with a browser, applications and persistent files. Use it yourself, connect an agent through MCP, and watch in Kitty or a private browser viewer.

Before you begin

This is a developer build. You need an Apple silicon Mac running macOS 14 or later, at least 8 GiB RAM, approximately 30 GiB free disk space for the default machine, and internet access for the first setup. The tested host is macOS 26.5; broader compatibility remains unverified.

Install Lima 2.2.1 and Go with toolchain download support, plus Git and Make. The build pins Go 1.26.9. Put limactl on PATH. Kitty 0.50.0 is the tested terminal; other terminals use the live browser fallback.

Build and start Linux

git clone https://github.com/ADITYADEV4145/AgentLinux.git
cd AgentLinux
make build
./bin/agent-linux doctor
./bin/agent-linux start --machine work

The first start downloads and provisions Debian 13 ARM64 with Xfce. It waits for the actual guest desktop service. Allow several minutes; errors and progress appear in your terminal. The developer build is not notarized.

Once installed on PATH, the single command agent-linux starts or resumes the default machine in an interactive terminal.

Connect your agent

./bin/agent-linux mcp-config --machine work --client codex

Review the printed configuration and follow the client setup guide. This command does not change your agent’s settings. The agent observes screenshots, acts inside Linux and checks the results. Arbitrary guest commands are available to an authorized agent.

Stay in control

./bin/agent-linux dashboard --local
./bin/agent-linux status --machine work --json
./bin/agent-linux stop --machine work

Open the private URL printed by the dashboard command. This public website cannot start or control your Mac’s VMs. Closing a viewer leaves Linux running; stop explicitly to release its allocated RAM. Saved guest files persist. In interactive Kitty, F2 hands control between you and your agent; Ctrl+] exits the viewer.

Use start --machine research for a separate workspace. Managed allocations default to half your Mac’s RAM and its logical CPU count minus two, with a minimum of one vCPU. Other host processes and unmanaged VMs are outside that budget.

Understand the boundaries

No host home-directory mount or host clipboard sharing is enabled by default. Guest networking can reach host and LAN services; this is not complete network isolation or a security guarantee. Read the security model before granting an agent access.

Cloud desktops are in development. Displayed cloud prices are planning prices, not an active checkout or subscription offer. Local software usage is free; your hardware, storage, internet and energy costs still apply.

Need help?

Use doctor, status --json and bounded logs, then consult troubleshooting. Never post keys, machine state or private screenshots in public issues.
